# UI glossary, English → Arabic

Read this when translating interface strings, to keep one Arabic term per English term. These are the forms most common in current Arabic apps (Saudi and Gulf first). Where two forms are both standard, both are listed; pick one per product.

Buttons are shown as verbal nouns (gender-neutral). The imperative form is in brackets where products commonly use it.

## Account and access

| English | Arabic | Notes |
|---|---|---|
| Sign in / Log in | تسجيل الدخول | Imperative: سجّل الدخول |
| Sign out / Log out | تسجيل الخروج | |
| Sign up / Create account | إنشاء حساب | Avoid bare `تسجيل`; it's ambiguous between sign in and sign up |
| Account | الحساب | My account: حسابي |
| Profile | الملف الشخصي | |
| Username | اسم المستخدم | |
| Password | كلمة المرور | Not `كلمة السر` in product UI |
| Forgot password? | نسيت كلمة المرور؟ | Fixed phrase; the past tense is the same written form for both genders |
| Reset password | إعادة تعيين كلمة المرور | |
| Show / hide password | إظهار / إخفاء كلمة المرور | |
| Remember me | تذكرني | |
| Email | البريد الإلكتروني | Label. `الإيميل` is informal |
| Phone number | رقم الجوال | `رقم الجوال` in Saudi/Gulf; `رقم الهاتف` / `رقم الموبايل` elsewhere |
| Verification code | رمز التحقق | OTP: رمز التحقق (لمرة واحدة) |
| Resend code | إعادة إرسال الرمز | |
| Two-factor authentication | المصادقة الثنائية | Also: التحقق بخطوتين |
